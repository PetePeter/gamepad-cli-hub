3 · Recreate flow

↻ Recreate as new closes the history modal and opens the existing create-task popup (ScheduledTasksTab in popup mode) prefilled from the history snapshot — title (+ " (copy)"), description, prompt, CLI type, params, working dir, mode, target session, and schedule kind. The scheduled time defaults to now + 1 hour so the user always picks a fresh time before saving. Nothing is created until the user confirms.

Done — task fired successfully Failed — shows error reason Cancelled — cancelled before/at fire

What is stored per run

Immutable snapshot of the task setup: title, description, prompt, cliType, cliParams, dirPath, mode, targetSessionId, scheduleKind + interval/cron/endDate — plus ranAt, outcome (done / failed / cancelled), error, and the spawned sessionId reference. Explicitly excluded: terminal stdout, PTY I/O, mirrored output. Entries older than 7 days are pruned on every append (rolling window, mirrors PlanBackupManager).

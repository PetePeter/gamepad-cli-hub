Show / hide

Toolbar 📄 Artifacts toggle (with badge) · ✕ on the panel · Ctrl+Shift+A + a gamepad binding. Collapsed = terminal full width + a slim right edge tab that pulses on a new artifact.

Why master/detail

Chips only suit ≤5. A rail scrolls to any count, supports search + sort, and keeps the reading pane stable while you scan the list.

Rail row anatomy

unread dot · title · MD/HTML tag · version count · relative time · hover 🗑. New artifact → auto-selected, others get an unread dot.

Space discipline

Rail collapses to a thin ‹ handle. Long lists virtualise. Pop-out window gives the rail + detail more room side-by-side.

Unchanged from before

Ephemeral per-session store (gone on close, not restored by recycle bin). Versioned. Export via native save dialog. MCP: show / update / delete / delete_all.
